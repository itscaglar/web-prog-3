# Web Programcılığı III

Bu repo, ders kapsamında dönem boyunca yapılan haftalık araştırma, sektör incelemesi ve uygulama görevlerini barındırmaktadır.

## Proje Hedefi

Dönem boyunca yapılan tüm haftalık çalışmalar birbirinden bağımsız ilerlemek yerine tek bir projede birleşecek ve dönem sonunda geliştirme geçmişi adım adım izlenebilen tam bir web uygulaması ortaya çıkacaktır.
